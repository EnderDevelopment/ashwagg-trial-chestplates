# Ashwagg's Trial Chestplates

Ashwagg's Trial Chestplates is a Minecraft texture pack that adds unique chestplates with different trims to your game. These chestplates are awarded to players when they first drop Ashwagg a Trials key, with each subsequent drop yielding a chestplate with a different trim material: copper, iron, and gold.

## Install

1. Download the texture pack from the GitHub repository.
2. In Minecraft, go to the "Resource Packs" menu.
3. Click on "Open Pack Folder".
4. Drag and drop the downloaded texture pack into the folder.
5. Go back to the "Resource Packs" menu and enable the texture pack.

## Use

1. Drop Ashwagg a Trials key.
2. Ashwagg will give you a chestplate with a unique trim.
3. The trim material will change with each subsequent drop: copper, iron, and gold.
